# Security and data handling

Do not put credentials, participant information or restricted model artifacts in
issues, pull requests or this repository. Report suspected exposure privately to
the project owner; do not include affected records in a public report. An ignore
rule does not remove a secret from history. No original Git history is included.

Checks are bounded static checks, not a proof that every possible secret or
re-identification risk is absent. Licenses, access and source review remain necessary.
