# Clinical Alzheimer Target Feasibility and Governance

## Scope

This note defines the boundary for any future clinical Alzheimer target. It does not change the current Method X or Method X-Cog claim.

- Current Method X target: `A-beta positive vs A-beta negative biomarker status`.
- Current Method X allowed inputs: T1 MRI with optional fixed tabular covariates `age`, `sex`, `education_years`, `apoe4_carrier`, and `mmse_base`.
- PET remains a label/target source for Method X, never an input.
- Method X-Cog remains exploratory and does not replace the Method X claim.

## Current Decision

A clinical output such as `Alzheimer disease present/absent` is blocked unless a separate clinical label is created and locked.

The following are not sufficient to claim clinical Alzheimer disease:

- A-beta positive vs A-beta negative status.
- PET or SUVR-derived status.
- Tau PET-derived status.
- Cognitive score differences without an independent diagnosis or conversion endpoint.
- A convenience relabeling of biomarker abnormality as clinical disease.

## Feasibility Artifact

The aggregate report generated by `scripts/clinical_ad_target_feasibility.py` is allowed to assess only:

- CN/MCI/AD dementia label availability.
- Diagnosis-at-visit availability.
- Conversion follow-up availability.
- Adjudicated diagnosis availability.
- Missingness and class balance at aggregate level.

The artifact must remain `FEASIBILITY_ONLY_NOT_TRAINED`. It must not produce subject-level labels, predictions, raw identifiers, raw paths, or model-ready clinical-label tables.

## Future Gates

Before any clinical Alzheimer model can be trained, all gates below must pass:

1. Define the target as a clinical label independent of PET-derived biomarker status.
2. Lock whether the endpoint is baseline status, diagnosis at visit, or future conversion.
3. Document the label source and adjudication rule, including unresolved ambiguity.
4. Run leakage review confirming PET, SUVR, centiloid, tau, and PET-derived features are not Method X or Method X-Cog inputs.
5. Report class balance, missingness, and follow-up coverage only in aggregate public artifacts.
6. Add tests that fail if a clinical Alzheimer output is claimed without the locked independent label.

## Reporting Language

Allowed current wording:

- `A-beta positive vs A-beta negative biomarker status`.
- `Future clinical Alzheimer target feasibility`.
- `Clinical label not yet approved for training`.

Forbidden current wording:

- `Alzheimer disease diagnosis model`.
- `Alzheimer present/absent classifier`.
- `Clinical Alzheimer prediction` as a Method X result.

## Interaction With Method Y

Method Y-PET/MM may later use PET images only under its own exploratory branch. That would remain separate from Method X and must not be folded into the non-invasive Method X claim.
