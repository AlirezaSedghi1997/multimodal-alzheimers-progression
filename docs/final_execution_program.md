# Final Execution Program

This project implements PET-free prediction of amyloid biomarker status on an A4/LEARN-style dataset. The operational priority is validity, defensibility, reproducibility, and scientific claim control, not higher AUC.

## Hard Constraints

Method X-Strict is the protected thesis object. Its inputs are strictly T1 structural MRI plus `age`, `sex`, `education_years`, `apoe4_carrier`, and `mmse_base`.

PET is label/target only. PET image, PET SUVR, centiloid as predictor, tau PET, PET-derived image features, scanner/site IDs as model features, cognitive variables beyond the fixed tabular set, blood biomarkers, future visits, raw subject IDs, and raw paths are forbidden as Method X inputs.

The target is `Aβ-positive vs Aβ-negative amyloid biomarker status`. It must not be described as Alzheimer disease diagnosis, Alzheimer disease classification, clinical Alzheimer diagnosis, or conversion-to-AD.

The locked holdout is a `locked pseudo-external evaluation`. It must not be used for tuning, model selection, calibration fitting, threshold selection, or DeLong superiority claims. It must not be called true external validation.

SF is an internal decoupling and stress-test instrument, not external or quasi-external validation.

Blood biomarkers belong only to Method Z / Bio-Cog and must be reported as a minimally invasive blood-biomarker branch.

All outputs are aggregate-level or hash-level only. Raw data remain read-only.

## Phase 0 Lock Artifacts

Before modeling, Phase 0 must produce the governance artifacts generated by `scripts/write_phase0_governance_artifacts.py`:

- label-freeze document with the placeholder `centiloid threshold: [INSERT PRESPECIFIED CUTOFF BEFORE MODELING]`
- branch-specific feature allowlist summary
- cohort-probe protocol
- deconfounding-scope document
- Phase 0 governance manifest

The centiloid cutoff must be inserted and frozen before modeling, model selection, hyperparameter tuning, performance inspection, calibration, or threshold selection. The cutoff must not change after model results are seen.

## Branch Positioning

Method X-Strict remains the protected thesis anchor.

Method X-Cog/SF is the main deconfounding-oriented exploratory/extended branch for testing whether PET-free clinical/cognitive signal survives cohort-label coupling. It is scientifically central for validity analysis, but it does not replace Method X-Strict as the protected thesis object.

MRI ROI / WMH / MRI Reads is an interpretable PET-free MRI extension. ICV-normalization is mandatory for volumetric ROIs, and unnormalized raw volumes must not be used as standalone predictors.

Bio-Cog / Method Z is a separate minimally invasive benchmark branch. It must not support the Method X non-invasive claim.

The Clinical Endpoint branch is exploratory and may only report frozen CDR worsening or PACC decline as a cognitive/clinical progression proxy, not Alzheimer diagnosis.

## Minimum Phase-2 MVP

If time is constrained, the following Phase-2 items are mandatory for all headline models:

1. 5-fold subject-grouped CV.
2. Locked pseudo-external evaluation.
3. Cramér's V / cohort-label audit.
4. Linear + nonlinear cohort-probe.
5. Calibration: Brier, ECE, reliability plot.
6. Bootstrap CI.
7. Label-shuffle control.
8. Feature permutation / ablation.
9. SF-aware stress-test where applicable.
10. Continuous centiloid within-cohort analysis.

DCA, matched/weighted subsets, train-SF/test-enrolled, train-enrolled/test-SF, additional temporal-gap refinements, and supplementary controls are completed after the Minimum Phase-2 MVP.

## Cohort-Probe Protocol

The cohort-probe is the headline validity metric.

The primary probe is a linear logistic regression on frozen embeddings/features predicting substudy or cohort. The secondary probe is a nonlinear calibrated GBT or small MLP on the same inputs. Always report linear probe AUC, nonlinear probe AUC, and the linear-vs-nonlinear gap.

Never claim deconfounding succeeded based on the linear probe alone.

## Train-Only Discipline

All deconfounders, normalizers, scalers, imputers, calibrators, ComBat/harmonizers, feature selectors, and threshold selectors must be fit on train folds only and applied out-of-sample. No held-out partition may influence fitted preprocessing or calibration statistics.

## Optional / Supplementary Items

Leakage-inflation negative control is optional and supplementary. If performed, report it in Supplementary Materials unless reviewers request otherwise. It must never be reported as model performance.

SSL is not part of the 12-week MVP. If attempted, it is stretch-only, single-level only, and never enters Method X-Strict.

External pretrained MRI embeddings are optional supplementary sensitivity comparisons only. They are skipped if licensing, preprocessing mismatch, or domain-shift risk is nontrivial.

## Claim Policy

Allowed claims:

- PET-free amyloid biomarker-status prediction.
- SF-aware internal stress-test / decoupling.
- Modest within-cohort MRI to continuous-amyloid association.
- Incremental value of cognition, ROI, WMH, MRI reads, and blood under separate claims.

Forbidden claims:

- Alzheimer disease diagnosis.
- True external validation.
- SF as external or quasi-external.
- PET/SUVR/centiloid/tau as Method X input.
- Blood inside the non-invasive Method X claim.
- Pooled confounded AUC as biological evidence.
- Subject-level or raw exports.
- Changing label cutoff after result inspection.

Recommended framing:

> This study predicts amyloid biomarker status, not Alzheimer disease diagnosis. Because the A4/LEARN catalog is strongly cohort-label coupled, Method X-Strict is preserved as the protected thesis anchor, while the core validity contribution is a confounding-resistant evaluation using SF as an internal decoupling/stress-test instrument, continuous centiloid, within-cohort analysis, calibration, ablation, and cohort-probe. PET-derived quantities are used only as labels/targets, never as Method X inputs.
